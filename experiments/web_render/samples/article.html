自研排版引擎渲染验证

HTML5 · CSS 层叠 · 块级流 · 行内断行 · 分页 · D3D11 / OpenGL

这一页由项目内置的 HTML 词法（re2c）与语法（bison）解析器读取，经 CSS 层叠、块级与行内排版后，由两套图形后端分别渲染。排版结果与后端无关，两种输出应当在像素级高度接近。

一、文本排版

中文段落用于验证逐字断行、避头尾规则与两端对齐。混排 Latin text with mixed spacing，以及标点（，。！？）“引号”和括号（示例）都应当落在合理的断行位置。行高采用 1.75 倍字号，段间距由外边距决定。

块级引用使用左侧粗边框、背景色与圆角。边框与背景由绘制层按盒模型绘制，圆角通过距离场计算覆盖率，两个后端共用同一套几何参数。

二、列表与行内元素

  • 无序列表项一：验证列表标记与左内边距。
  • 无序列表项二：链接应显示下划线与主题色。
  • 无序列表项三：包含 行内高亮 的片段。

卡片区块：白色背景、1 像素边框、14 像素圆角、内边距 22/26 像素。内部段落与外部文本共享同一套行内排版流程。
